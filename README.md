# 🏋️ AI Real-Time Gym Coach

> A webcam-based workout assistant that tracks your exercise form, counts reps and sets, and gives real-time voice coaching using pose estimation and an LLM.

## 📌 Problem
Most people train without a coach and repeat poor form without noticing, which hurts progress and can cause injury. This project gives instant, spoken feedback using only a webcam.

## ✨ Features
- **Real-time pose detection** with MediaPipe Pose Landmarker
- **5 supported exercises:** squats, push-ups, dumbbell biceps curls, shoulder press, lunges
- **Rep and set tracking** with configurable targets
- **Form analysis** using joint angles, body alignment, squat depth and balance
- **AI coaching** generated by Gemini 3.5 Flash-Lite through the Google Gemini API
- **Voice feedback** with gTTS text-to-speech
- **Workout history** stored locally in SQLite
- Simple username-based session tracking
- Static **landing page** for the project

## 🏗️ How It Works
```
Webcam → streamlit-webrtc → MediaPipe Pose Landmarker
      → Exercise detector (angles, alignment, depth)
      → Rep / set counter (threshold logic)
      → Coaching event → Gemini LLM → gTTS voice
      → SQLite workout history
```
Each exercise has its own detector (`detectors/squat.py`, `pushup.py`, and so on) built on a shared `BaseExercise` class, so adding a new exercise only needs a new detector file.

## 🚀 Installation

**Requirements:** Python 3.10 or 3.11, a webcam, internet (for Gemini and gTTS), and a [Gemini API key](https://aistudio.google.com/apikey).

```bash
git clone https://github.com/Nitesh-45/AI-RealTime-GYM-Coach.git
cd AI-RealTime-GYM-Coach

python3.11 -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
cd "Main App"
```

On Linux, also install the system packages listed in `Main App/packages.txt`.

### Configure your API key
```bash
export GEMINI_API_KEY="your_gemini_api_key"      # Windows PowerShell: $env:GEMINI_API_KEY="your_gemini_api_key"
```
Or create `Main App/.streamlit/secrets.toml`:
```toml
GEMINI_API_KEY = "your_gemini_api_key"
```

> ⚠️ **Never commit `.env`, `secrets.toml` or `data.db`.** Keep them in `.gitignore` and share only an `.env.example`.

## ▶️ Usage
```bash
streamlit run main.py
```
Open `http://localhost:8501`, then:
1. Enter a unique username
2. Choose an exercise in the sidebar
3. Set target sets and reps
4. Click **Start Workout** and allow camera access
5. Stay fully in frame and perform the exercise
6. Click **End Workout** when you are done

## 🧯 Troubleshooting
- **Pose model not found:** run from `Main App/` and confirm `ml_models/pose_landmarker_full.task` exists
- **Webcam not starting:** allow browser camera permission, close other apps using the camera, use localhost or HTTPS
- **No AI voice feedback:** check `GEMINI_API_KEY` and your internet connection
- **Install errors:** use Python 3.10/3.11 and upgrade pip first

## ⚠️ Limitations & Future Work
- Accuracy depends on camera angle, lighting and full-body visibility
- Prototype for local use; it does not replace a qualified trainer or medical advice
- Planned: more exercises, a progress dashboard, Dockerised deployment, automated tests
